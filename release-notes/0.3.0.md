## 3 Agents v0.3.0

- **조합 선택**: 입력창 위에서 `ChatGPT + Gemini(API) + Claude` 또는 `ChatGPT + Antigravity(CLI) + Claude` 를 고를 수 있습니다. 기본은 지금과 같은 Gemini(API)입니다.
- **Antigravity(agy) CLI 연동(실험적)**: 설정에서 모델과 추론 노력을 고릅니다. 켤 때 약관 경고를 확인해야 합니다.
- 안전 장치: 도구 사용 금지 지시, 권한 확인 건너뛰기 옵션 미사용, 셸 미경유 실행, 긴 프롬프트 차단.

> Antigravity 는 Google 약관상 회색지대이고 실제 `agy` 로 충분히 검증되지 않았습니다. 쓰지 않으면 아무 영향이 없습니다.
