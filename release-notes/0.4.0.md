## 3 Agents v0.4.0

- **초기화 버튼**: 입력창과 결과(탭·카드)를 한 번에 비웁니다. 진행 중이면 먼저 중단합니다.
- **기록 자동 저장**: 질문마다 마크다운 노트 1개가 저장됩니다(합의 답변, 한눈에 보기 체크리스트, 개별 답변). 중단·실패해도 답변이 하나라도 있으면 `미완료`로 저장합니다.
- **저장 위치 설정 / 옵시디언 볼트 지원**: 설정(⚙) → 기록 저장에서 폴더를 지정하면 노트가 그 폴더에 쌓입니다. 노트 상단에 frontmatter(날짜·질문·모드·신뢰도·결론·태그)가 들어갑니다. 저장 on/off, 개별·전체 삭제 지원. 자동 삭제는 없습니다.
- **기록 보기**: 헤더의 기록 버튼에서 검색하고, 선택하면 결과 화면을 그대로 복원합니다. 옵시디언에서 열기 링크 제공.
- **조합 선택을 설정으로 이동**: 입력창 버튼은 다시 한 줄로 정리했습니다.

> 노트는 암호화되지 않은 일반 텍스트로 저장됩니다. 앱이 만든 노트(`source: 3-agents`)만 목록·삭제 대상이며, 폴더의 다른 노트는 건드리지 않습니다.
