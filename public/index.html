설정

로그인(CLI): 이 컴퓨터에 설치·로그인된 공식 CLI를 실행합니다. API 키가 필요 없고 구독 사용량을 씁니다. API 키: 키는 이 브라우저에만 저장되고 로컬 서버를 거쳐 각 회사 API로만 전송됩니다.

기록 저장

질문과 답변을 마크다운 노트(질문 1개 = 파일 1개)로 저장합니다. 옵시디언 볼트 안의 폴더를 지정하면 바로 노트로 보입니다. (예: D:\Vault\3-Agents) 볼트 전체보다 하위 폴더를 권합니다.

데스크탑 앱

새 버전이 있으면 업데이트 창이 자동으로 뜹니다. 로그인이나 토큰은 필요 없습니다.

기록

    Antigravity 사용 전 확인

    이 앱이 Antigravity CLI(agy)를 대신 실행해서 Google 계정으로 질의합니다.

    • 약관 위험: Google 추가 약관은 제3자 도구를 통한 접근을 제한하며, 자동화된 사용이 감지되면 Antigravity/Gemini CLI 계정이 정지될 수 있습니다. 개인 PC에서 본인 계정으로 쓰는 경우가 허용되는지는 공식 확인이 없습니다.
    • 이 앱이 하는 일: agy 를 실행만 합니다. 로그인 토큰이나 자격 증명 파일은 읽지 않고, 파일·명령 도구를 쓰지 않도록 지시하며, 권한 확인을 건너뛰지 않습니다.
    • 사용량: Google AI 구독 한도에서 차감됩니다.

    중요한 계정이라면 사용하지 마세요. 언제든 조합을 Gemini(API)로 되돌릴 수 있습니다.
